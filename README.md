# RFID Attendance System

## Overview
An RFID-based attendance system built using ESP8266 and RC522 RFID module.

## Components Used
- Arduino Uno
- RC522 RFID Reader
- RFID Tags
- Jumper Wires
- Breadboard

## Features
- Automatic attendance marking
- Unique card identification
- Serial monitor output

## How to Run

3. Scan RFID cards.
4. View attendance in Serial Monitor.
